# CREATIVE CONTROL

A modern professional wrestling booking and promotion management game by Mike Lopaz.

## Current public build

CREATIVE CONTROL 2.3.1 — Owner Mode / Continuous Music

The repository is prepared for GitHub Pages. The root `index.html` launches the verified public web build while the project is transitioned fully onto GitHub hosting.

### Current game features

- Owner Mode and GM selection
- Monthly calendar and event scheduling
- January 2026 wrestling universe
- Roster, contracts, teams, factions, titles, staff, and development
- Booking Engine 2.0
- Living World rival promotion simulation
- Creative Team, Media & Fans, and Policies & Discipline
- Fictional life/backstage event simulation
- Save manager and browser persistence
- Continuous official CREATIVE CONTROL title/game music

## GitHub Pages setup

In repository **Settings → Pages**, set **Source** to **Deploy from a branch**, select **main** and **/(root)**, then Save.

Future releases can replace the current wrapper with the full static build without changing the public Pages address.
